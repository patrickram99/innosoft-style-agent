## 1. Historia de usuario

**Como** administrador, **quiero** un registro de cada ejecución con tiempos por etapa, reglas evaluadas, hallazgos y errores, **para** diagnosticar fallos y medir el rendimiento.

## 2. Propósito

Base de observabilidad y de verificación de RNF-03 (análisis < 3 min) y RNF-04 (trazabilidad).

## 3. Alcance

**Incluye**

- Tabla `runs` y `run_stages`.
- Consulta `GET /runs?manuscript_id=`.
- Registro de versión de reglas (hash), versión de prompt y versión del agente.

**No incluye**

- Consumo de Gemini detallado (US-29).
- Panel gráfico (US-32).

## 4. Entradas

| Entrada | Origen / formato | Restricciones |
|---|---|---|
| Eventos de cada etapa | Pipeline | Inicio, fin, resultado, error. |

## 5. Salidas

| Salida | Destino / formato | Descripción |
|---|---|---|
| `runs` | PostgreSQL | `{id, manuscript_id, started_at, finished_at, status, rules_hash, prompt_version, app_version, rules_evaluated, findings_count, errors[]}` |
| `run_stages` | PostgreSQL | `{run_id, stage, started_at, duration_ms, status, detail}` |

## 6. Reglas de comportamiento

1. Etapas: `intake`, `extract_text`, `sections`, `figures`, `citations`, `references`, `validate`, `suggest`, `publish`.
2. Cada `rule_error` del motor se registra con `rule_id` y traza resumida.
3. Un fallo de etapa marca el run como `failed` pero conserva el manuscrito y lo ya calculado (RNF-06).

## 7. Excepciones y flujos alternativos

| Condición | Comportamiento esperado | Ref. |
|---|---|---|
| Fallo al escribir el registro | Se escribe en el log de aplicación; no interrumpe el análisis. | — |

## 8. Criterios de aceptación

**AC-01**

```gherkin
Dado un manuscrito analizado
Cuando se consulta `GET /runs?manuscript_id=…`
Entonces se obtienen las duraciones por etapa, reglas evaluadas y n.º de hallazgos
```

**AC-02**

```gherkin
Dado un artículo original de 15 páginas
Cuando termina el análisis
Entonces `finished_at − started_at` < 3 min (RNF-03)
```

**AC-03**

```gherkin
Dado una regla que falla
Cuando se consulta el run
Entonces aparece en `errors` con su `rule_id`
```

## 1. Historia de usuario

**Como** agente, **quiero** tolerar errores transitorios de Gemini y respetar un presupuesto de tokens por manuscrito, **para** que el análisis siempre termine y el costo sea predecible.

## 2. Propósito

Asegura RNF-06 en la etapa de LLM: ningún manuscrito queda bloqueado por la API externa.

## 3. Alcance

**Incluye**

- Backoff exponencial con jitter, 3 intentos, ante timeout, 429 y 5xx.
- Presupuesto de tokens por manuscrito configurable.
- Fallback determinístico para el resto de hallazgos cuando se agota el presupuesto o fallan los reintentos.
- Aviso al editor en la cola y en la vista del manuscrito.

**No incluye**

- Validación de esquema (US-16).
- **Recorte del MVP (replanificación del 29-sep):** en esta release entra reintentos con backoff y fallback; el presupuesto de tokens por manuscrito pasa a R2.

## 4. Entradas

| Entrada | Origen / formato | Restricciones |
|---|---|---|
| Configuración | Variables de entorno | `GEMINI_MAX_RETRIES=3`, `GEMINI_TOKEN_BUDGET_PER_MANUSCRIPT`, `GEMINI_TIMEOUT_S`. |

## 5. Salidas

| Salida | Destino / formato | Descripción |
|---|---|---|
| Sugerencias | `suggestions` | `origen=llm` o `fallback`. |
| Aviso | `manuscripts.warnings` | `token_budget_exceeded`, `llm_unavailable`. |

## 6. Reglas de comportamiento

1. Esperas base 1 s, 2 s, 4 s (+ jitter ≤ 250 ms); errores 4xx distintos de 429 no se reintentan.
2. Se descuentan los tokens reales reportados por la API (entrada + salida).
3. Al superar el presupuesto, las sugerencias restantes se generan con fallback y se añade el aviso.
4. El orden de generación es por severidad (alta → baja) para gastar el presupuesto en lo más importante.

## 7. Excepciones y flujos alternativos

| Condición | Comportamiento esperado | Ref. |
|---|---|---|
| Cuota diaria agotada | Todas las sugerencias restantes en fallback; aviso `llm_unavailable`. | ALT-05 |
| Timeout en el tercer intento | Fallback para ese hallazgo; continúa con el siguiente. | ALT-05 |

Flujos alternativos del catálogo relacionados:

- **ALT-05** — Gemini no responde, excede cuota o devuelve JSON inválido (actividad D)

## 8. Criterios de aceptación

**AC-01**

```gherkin
Dado Gemini responde 503 dos veces y luego 200
Cuando se genera una sugerencia
Entonces se usa la respuesta del tercer intento
```

**AC-02**

```gherkin
Dado un presupuesto de 2 000 tokens y 20 hallazgos
Cuando se agota el presupuesto en el hallazgo 8
Entonces los hallazgos 9..20 tienen `origen=fallback` y el editor ve el aviso
```

**AC-03**

```gherkin
Dado Gemini caído
Cuando se procesa un manuscrito
Entonces el manuscrito llega a `ready_for_review` con sugerencias `fallback`
```

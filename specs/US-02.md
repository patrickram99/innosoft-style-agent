# US-02 · Plugin OJS: hook al completar un envío

## 1. Historia de usuario

**Como** editor, **quiero** que el análisis se dispare solo al completar un envío, **para** no tener que hacer nada manual.

## 2. Propósito

Conecta OJS 3.1.2.1 con el agente: un plugin genérico escucha el evento de envío completado, obtiene el archivo del manuscrito y lo remite a `POST /manuscripts` sin afectar la experiencia del autor.

## 3. Alcance

**Incluye**

- Plugin genérico (PHP) para OJS 3.1.2.1 instalable desde el administrador de plugins.
- Registro en el hook de finalización del envío (paso 4 del asistente).
- Obtención del archivo de envío (galerada original, etapa *Envío*) y de sus metadatos.
- Llamada HTTP a US-01 con timeout corto y token de servicio.
- Pantalla de configuración: URL del agente, token, secciones habilitadas.

**No incluye**

- Publicación del comentario (US-24).
- Notificaciones por correo (US-27).
- Soporte a otras versiones de OJS.

## 4. Entradas

| Entrada | Origen / formato | Restricciones |
|---|---|---|
| Evento de envío completado | Hook de OJS 3.1.2.1 | Solo envíos nuevos o revisiones del autor. |
| Archivo de envío | `SubmissionFile` de la etapa de envío | PDF; si hay varios, el marcado como archivo principal. |
| Configuración del plugin | Ajustes del plugin por revista | URL, token, secciones activas. |

## 5. Salidas

| Salida | Destino / formato | Descripción |
|---|---|---|
| Petición a US-01 | HTTP multipart | PDF + metadatos (`submission_id`, `section_id`, `title`, `locale`, `revision`). |
| Registro en log de OJS | `error_log` / log del plugin | Éxito o error con `submission_id`. |

## 6. Reglas de comportamiento

1. El envío del autor **nunca** se bloquea ni muestra error por fallos del agente (RNF-06).
2. La llamada al agente tiene timeout ≤ 10 s; el trabajo pesado ocurre en el agente de forma asíncrona.
3. Solo se envían manuscritos de secciones habilitadas en la configuración.
4. El token se almacena en los ajustes del plugin, no en el código.

## 7. Excepciones y flujos alternativos

| Condición | Comportamiento esperado | Ref. |
|---|---|---|
| Agente no disponible / timeout | Se registra en el log de OJS con `submission_id`; el envío del autor termina con normalidad. | RNF-06 |
| El envío no tiene archivo PDF | Se registra advertencia y no se llama al agente. | — |
| Sección no habilitada | No se llama al agente; se registra como ignorado. | ALT-07 |

Flujos alternativos del catálogo relacionados:

- **ALT-07** — Sección OJS no mapeada (p. ej., editorial, carta) (actividad A)

## 8. Criterios de aceptación

**AC-01**

```gherkin
Dado el plugin activo y un autor que completa el paso 4 del envío
Cuando OJS dispara el hook
Entonces el agente recibe el PDF y los metadatos y crea un manuscrito `received`
```

**AC-02**

```gherkin
Dado el agente apagado
Cuando un autor completa un envío
Entonces el autor ve la confirmación habitual de OJS y el log del plugin registra el fallo
```

**AC-03**

```gherkin
Dado el plugin desactivado
Cuando un autor completa un envío
Entonces no se realiza ninguna llamada al agente
```

## 1. Historia de usuario

**Como** agente, **quiero** conocer, para cada imagen, su página, bbox, dimensiones en píxeles, DPI efectivo y pie de figura asociado, **para** validar las reglas de figuras.

## 2. Propósito

Las figuras mal dimensionadas, pequeñas o mal etiquetadas son el principal problema de estilo de la revista. Esta historia produce los datos objetivos sobre los que operan RE-20..RE-25.

## 3. Alcance

**Incluye**

- Listado de imágenes rasterizadas por página con `bbox` y píxeles reales (`get_images` / `get_image_info`).
- Cálculo de DPI efectivo = píxeles / tamaño impreso en pulgadas (por eje).
- Detección de dibujos vectoriales (`get_drawings`) agrupados por región y marcados como `vector`.
- Asociación del pie: primer bloque bajo el bbox que empiece con *Figura* o *Fig.* (tolerancia 40 pt).
- Manuscrito sin figuras → lista vacía (ALT-03).

**No incluye**

- Validación de las reglas (US-10, US-11).
- Detección de recortes o desbordes (US-35).
- Tablas (US-34).

## 5. Salidas

| Salida | Destino / formato | Descripción |
|---|---|---|
| `figures` | JSONB en `documents` | Lista ordenada por aparición (página, luego y, luego x). |
| Miniatura | `storage/{id}/fig-{n}.png` | Recorte renderizado para la evidencia de US-20. |

**Contrato de ejemplo**

```json
{"order": 3, "page": 5, "kind": "raster",
 "bbox": [90.0, 200.0, 520.0, 430.0],
 "width_px": 1200, "height_px": 640,
 "print_width_in": 5.97, "print_height_in": 3.19,
 "dpi_x": 201.0, "dpi_y": 200.6,
 "caption": {"text": "Figura 3. Arquitectura del sistema", "number": 3,
             "position": "below", "bbox": [150.0, 436.0, 460.0, 450.0],
             "font": "TimesNewRomanPSMT", "size": 10.0}}
```

## 6. Reglas de comportamiento

1. Una imagen que aparece varias veces (mismo `xref`) se reporta una vez por ocurrencia en página.
2. Se ignoran imágenes decorativas menores a un área mínima configurable (inicial: 1 % del área de página), p. ej. logos de cabecera.
3. Para `kind=vector` no se calcula DPI (`dpi_x=dpi_y=null`); RE-21 no aplica.
4. Si no hay bloque *Figura/Fig.* a ≤ 40 pt debajo, se busca arriba; si se encuentra arriba, `position=above`; si no, `caption=null`.
5. El número del pie se extrae con regex tolerante (`Figura 3.`, `Fig. 3:`, `FIGURA 3 -`).

| ID | Regla | Severidad | Fuente | Detectable |

## 7. Excepciones y flujos alternativos

| Condición | Comportamiento esperado | Ref. |
|---|---|---|

| Imagen compuesta por varios mosaicos | Se fusionan bboxes contiguos en una sola figura si comparten pie. | — |

## 8. Criterios de aceptación

**AC-01**

```gherkin
Dado un PDF con 3 figuras raster con pie
Cuando se extraen figuras

```

**AC-02**

```gherkin
Dado una figura de 1200 px de ancho impresa a 6 pulgadas
Cuando se calcula el DPI
Entonces `dpi_x` es 200 (±1)
```

**AC-03**

```gherkin
Dado un PDF generado desde LaTeX con figura vectorial
Cuando se extraen figuras
Entonces la figura aparece con `kind=vector` y sin DPI
```

**AC-04**

```gherkin
Dado el PDF sin figuras del corpus
Cuando se extraen figuras
Entonces `figures=[]` y no hay errores
```

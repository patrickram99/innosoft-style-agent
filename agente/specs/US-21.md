## 1. Historia de usuario

**Como** editor, **quiero** aceptar, rechazar o editar cada sugerencia, o aceptar todas las de una categoría, **para** controlar qué recibe el autor.

## 2. Propósito

Materializa la revisión humana obligatoria (RNF-01) y genera los datos de decisión para la trazabilidad (RNF-04) y las métricas de aceptación.

## 3. Alcance

**Incluye**

- Acciones por sugerencia: aceptar, rechazar (con motivo opcional), editar.
- Acción masiva: aceptar todas las de una categoría.
- Conservación del texto original y del editado.
- Registro de usuario y hora de cada decisión.
- Control de concurrencia entre editores (ALT-12).

**No incluye**

- Sugerencias manuales (US-22).
- Publicación (US-24).

## 4. Entradas

| Entrada | Origen / formato | Restricciones |
|---|---|---|
| Decisión | `POST /decisions` | `{suggestion_id, action: accept\|reject\|edit, text?, reason?, version}`; aceptación masiva: `{manuscript_id, categoria, action: accept_all}` |
| Identidad del editor | Sesión | — |

## 5. Salidas

| Salida | Destino / formato | Descripción |
|---|---|---|
| Decisión | Tabla `decisions` (histórico) | `{suggestion_id, action, original_text, edited_text, reason, user_id, decided_at}` |
| Estado de la sugerencia | `suggestions.status` | `proposed → accepted \| rejected \| edited` (00-producto §7.2). |
| Estado del manuscrito | `in_review` → listo para publicar | Cuando no quedan pendientes. |

## 6. Reglas de comportamiento

1. Cada decisión se guarda como nuevo registro; el histórico no se sobreescribe.
2. Editar implica aceptar el texto editado; el original permanece intacto.
3. Concurrencia: bloqueo optimista con `version`; si la sugerencia cambió desde que se cargó, se responde 409 con el estado actual y el editor decide de nuevo. Toda decisión queda registrada (ALT-12).
4. El botón *Publicar* se habilita solo cuando no hay sugerencias `proposed`.

## 7. Excepciones y flujos alternativos

| Condición | Comportamiento esperado | Ref. |
|---|---|---|
| Dos editores deciden sobre la misma sugerencia | El segundo recibe 409 y ve la decisión del primero. | ALT-12 |
| El editor rechaza todas | Se ofrece marcar "sin observaciones" (US-23). | ALT-06 |

Flujos alternativos del catálogo relacionados:

- **ALT-06** — Editor rechaza todas las sugerencias (actividad E/F)
- **ALT-12** — Dos editores revisan el mismo manuscrito (actividad E)

## 8. Criterios de aceptación

**AC-01**

```gherkin
Dado una sugerencia pendiente
Cuando el editor la edita y guarda
Entonces se conservan el texto original y el editado con usuario y hora
```

**AC-02**

```gherkin
Dado 5 sugerencias pendientes de la categoría figuras
Cuando el editor pulsa *Aceptar todas*
Entonces las 5 quedan `accepted` con 5 registros de decisión
```

**AC-03**

```gherkin
Dado dos editores con la misma sugerencia abierta
Cuando ambos deciden
Entonces el segundo recibe 409 y ambas acciones quedan en el registro
```

# US-16 · Validar el esquema de respuesta del LLM

## 1. Historia de usuario

**Como** agente, **quiero** rechazar respuestas del LLM que no cumplan el esquema o alteren el `rule_id`, **para** proteger la trazabilidad regla → sugerencia.

## 2. Propósito

Garantiza RNF-04: ninguna sugerencia se desvincula de su regla, aun si el modelo alucina o devuelve formato incorrecto. Define el fallback determinístico.

## 3. Alcance

**Incluye**

- Modelo Pydantic de respuesta (`rule_id`, `sugerencia`, `ejemplo_corregido` opcional).
- Comprobación de que `rule_id` devuelto = `rule_id` enviado.
- Un reintento ante respuesta inválida.
- Fallback: `mensaje` de la regla con marcadores rellenados, `origen=fallback`.

**No incluye**

- Reintentos por errores de red o cuota (US-18).

## 4. Entradas

| Entrada | Origen / formato | Restricciones |
|---|---|---|
| Respuesta cruda de Gemini | US-15 | Texto/JSON. |
| Hallazgo y regla originales | US-10..14, US-09 | — |

## 5. Salidas

| Salida | Destino / formato | Descripción |
|---|---|---|
| Sugerencia válida | `suggestions` | `origen=llm` o `origen=fallback`. |
| Registro de validación | Run (US-28) | Motivo del rechazo y número de intento. |

## 6. Reglas de comportamiento

1. Una respuesta es válida si: es JSON, cumple el esquema, `rule_id` coincide, `sugerencia` no está vacía y tiene ≤ 600 caracteres.
2. Si es inválida se reintenta **una** vez con el mismo prompt más una instrucción de corrección de formato.
3. Si el segundo intento falla, se genera la sugerencia con el `mensaje` de la regla y los valores del hallazgo (`{figura}`, `{pagina}`, `{encontrado}`, `{esperado}`).
4. Las sugerencias `fallback` se muestran al editor con una etiqueta distintiva (US-20).

## 7. Excepciones y flujos alternativos

| Condición | Comportamiento esperado | Ref. |
|---|---|---|
| JSON inválido dos veces | Fallback determinístico. | ALT-05 |
| `rule_id` cambiado por el modelo | Se descarta; reintento; luego fallback. | ALT-05 |
| Sugerencia con datos personales detectados | Se descarta y se usa fallback (defensa adicional a US-17). | RNF-02 |

Flujos alternativos del catálogo relacionados:

- **ALT-05** — Gemini no responde, excede cuota o devuelve JSON inválido (actividad D)

## 8. Criterios de aceptación

**AC-01**

```gherkin
Dado una respuesta con `rule_id=RE-21` para un hallazgo RE-20
Cuando se valida
Entonces se descarta y se reintenta una vez
```

**AC-02**

```gherkin
Dado dos respuestas inválidas seguidas
Cuando se valida
Entonces se guarda la sugerencia `fallback` con el mensaje de RE-20 rellenado
```

**AC-03**

```gherkin
Dado una respuesta válida
Cuando se valida
Entonces se guarda con `origen=llm` sin reintentos
```

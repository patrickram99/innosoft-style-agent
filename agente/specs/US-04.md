## 1. Historia de usuario

**Como** agente, **quiero** el texto por página con coordenadas, **para** ubicar cada hallazgo.

## 2. Propósito

Produce la representación base del documento (`Document`) sobre la que trabajan todas las demás extracciones y reglas. Sin texto no hay reglas.

## 3. Alcance

**Incluye**

- Servicio `extract_text(pdf) → Document` con PyMuPDF (`page.get_text("dict")`).
- Por página: número, ancho, alto y bloques con `bbox`, texto, fuente, tamaño y banderas (negrita/cursiva).
- Detección de PDF sin capa de texto o corrupto → estado `unreadable` (ALT-01).
- Persistencia del `Document` como JSONB.

**No incluye**

- OCR de PDFs escaneados (fuera de alcance del MVP).
- Detección de secciones (US-05) y figuras (US-06).

## 4. Entradas

| Entrada | Origen / formato | Restricciones |
|---|---|---|
| PDF | `storage/{id}.pdf` | Recibido por US-01, estado `received`. |

## 5. Salidas

| Salida | Destino / formato | Descripción |
|---|---|---|
| `Document` | JSONB en tabla `documents` | `{page, width, height, blocks[{bbox, text, font, size, flags}]}` por página. |
| Estado | `extracted` o `unreadable` | Con motivo si es `unreadable`. |

**Contrato de ejemplo**

```json
{
  "manuscript_id": "7f3c…",
  "pages": [
    {"page": 1, "width": 612, "height": 792,
     "blocks": [{"bbox": [72.0, 90.1, 540.2, 130.4], "text": "Título del artículo",
                 "font": "TimesNewRomanPS-BoldMT", "size": 18.0, "bold": true, "italic": false}]}
  ]
}
```

## 6. Reglas de comportamiento

1. Las coordenadas se expresan en puntos PDF (1/72 in) con origen arriba-izquierda (convención PyMuPDF).
2. Se conserva el orden de lectura que entrega PyMuPDF; no se reordenan columnas en esta historia.
3. Un PDF es `unreadable` si no se puede abrir o si el promedio de caracteres extraíbles por página es menor que el umbral configurable (inicial: 50).
4. Tiempo de extracción < 10 s para 30 páginas en el entorno de referencia.

## 7. Excepciones y flujos alternativos

| Condición | Comportamiento esperado | Ref. |
|---|---|---|
| PDF escaneado (sin texto) | Estado `unreadable`, motivo `no_text_layer`, aviso al editor en la cola. | ALT-01 |
| PDF corrupto o cifrado | Estado `unreadable`, motivo `corrupt` o `encrypted`; el archivo original se conserva. | ALT-01, RNF-06 |
| Página vacía intermedia | Se incluye con `blocks: []`; no invalida el documento. | — |

Flujos alternativos del catálogo relacionados:

- **ALT-01** — PDF sin capa de texto (escaneado) o corrupto (actividad B)

## 8. Criterios de aceptación

**AC-01**

```gherkin
Dado un PDF de texto de 15 páginas
Cuando se ejecuta la extracción
Entonces el `Document` tiene 15 páginas con bloques, bbox, fuente y tamaño y el estado es `extracted`
```

**AC-02**

```gherkin
Dado el PDF escaneado del corpus
Cuando se ejecuta la extracción
Entonces el estado es `unreadable` con motivo `no_text_layer` y el editor ve el aviso
```

**AC-03**

```gherkin
Dado un PDF de 30 páginas
Cuando se mide la extracción
Entonces termina en menos de 10 s
```

**AC-04**

```gherkin
Dado una extracción exitosa
Cuando se consulta la base de datos
Entonces el `Document` está persistido como JSONB y asociado al `manuscript_id`
```
